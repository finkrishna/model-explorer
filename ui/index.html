1. Choose three models

Each dropdown lists all ten catalogued models and any can be selected. The three cached Qwen2 checkpoints (✔ runs here) produce measured internals; the rest are reference-only — their column shows verified specs from the model card, but nothing is run for them. Base and instruction-tuned models are tagged.

2. Enter one shared prompt

Decoding is greedy (deterministic) by default. The prompt, the answers and all activations exist only in local memory for the latest run; nothing is written to disk, logged, or sent off your machine.
